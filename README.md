# Crime Hotspot Analysis and Identification

## Project Description
This project is about analyzing crime data using Python. It helps us understand crime records in different cities and study crime types, victim details, and case status.

## Objectives
- To clean and prepare the crime dataset.
- To analyze crime records using Python.
- To create graphs and understand crime patterns.
- To find useful information from the dataset.

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Dataset
Indian Crimes Dataset from Kaggle.

Dataset Link: https://www.kaggle.com/datasets/sudhanvahg/indian-crimes-dataset

## Analysis Performed
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Statistical Analysis
- Data Visualization
- Key Insights and Conclusion

## How to Run
1. Install Python and Jupyter Notebook.
2. Install the required Python libraries.
3. Open the project notebook.
4. Keep the CSV dataset in the correct folder.
5. Run the notebook cells in order.
